# Alternis 2.8.1 — Corrections visuelles

Corrections de deux défauts d'affichage signalés sur la refonte 2.8 :

- **Panneau de notifications et menus transparents** : le panneau des
  notifications, le menu du profil, les fenêtres et les notifications laissaient
  voir le contenu derrière (texte illisible). Ils sont désormais opaques.
- **Halo qui débordait des cartes** : sur certains téléphones (iOS), le halo
  décoratif des cartes de statistiques débordait en cercle clair hors du cadre.
  Le halo est maintenant proprement contenu.

Aucune modification technique : uniquement la feuille de style.
