# Alternis 2.8.2 — Corrections mobile & cases à cocher

- **Cases à cocher / sélecteurs repensés** : les ronds gris bruts (sélection
  des candidatures, options) sont remplacés par des cases élégantes — carré
  arrondi pour les cases, cercle pour les choix uniques, coche blanche sur
  dégradé violet-cyan une fois sélectionnées. Appliqué partout.
- **Fin du "sandwich" sur mobile** : les écrans à deux colonnes (Administration
  → Notifications, fiche entreprise, tableau de bord, annuaire) s'empilent
  désormais proprement sur une seule colonne sur téléphone, sans contenu coupé.
- **Collaboration & réglages** : sur mobile, les lignes réglage/collaboration
  passent en colonne — le sélecteur de droits, l'étiquette, le badge de rôle et
  le bouton « Révoquer » ne sont plus coupés à droite.
- **Textes longs** : les adresses e-mail et longs libellés ne débordent plus.

Uniquement la feuille de style ; aucune modification technique.
